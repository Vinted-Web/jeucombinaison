# Devine la règle secrète - PWA

Application autonome prête pour GitHub Pages.

## Mise en ligne
1. Créez un dépôt GitHub, par exemple `devine-la-regle`.
2. Ajoutez tout le contenu de ce dossier à la racine du dépôt.
3. Ouvrez **Settings > Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez la branche **main** et le dossier **/(root)**, puis cliquez sur **Save**.
6. L'adresse sera généralement `https://VOTRE-IDENTIFIANT.github.io/devine-la-regle/`.

## Installation sur téléphone
- Android / Chrome : ouvrez l'adresse, puis utilisez **Installer l'application** ou **Ajouter à l'écran d'accueil**.
- iPhone / Safari : ouvrez l'adresse, touchez **Partager**, puis **Sur l'écran d'accueil**.

## Mise à jour
Après une modification importante, augmentez la version `devine-regle-v1` dans `service-worker.js` en `v2`, `v3`, etc., afin de renouveler le cache hors ligne.
